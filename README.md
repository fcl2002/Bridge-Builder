# Bridge Builder - Structural Simulation Game

## 📋 Project Overview

A 2D physics-based bridge construction game where players design and test structural integrity in real-time. The simulation uses realistic physics to evaluate bridge stability under stress.

**Duration:** 4 Sprints (Feb 11 - Apr 14, 2026)

## 🔗 Epic-Developer Relationship

Each **Epic** maps directly to one **developer**:

- Each developer owns all user stories within their Epic
- Developers are autonomous within their domain but collaborate on integration points
- Cross-Epic dependencies are identified in user story acceptance criteria

## 📊 Development Workflow

1. **Sprint Planning:** Team selects user stories from their respective Epics
2. **Development:** Each developer implements stories within their domain
3. **Integration:** Developers coordinate on interface contracts and integration testing
4. **Sprint Review:** Demo completed features and gather feedback
